# research/files/

Drop PDFs here if you'd rather self-host a paper (or your CV, a slide deck,
etc.) instead of linking to a publisher page.

To use one: open `js/data.js`, find (or add) the entry in the `PAPERS`
array, and set:

```js
link: "research/files/your-file-name.pdf",
```

No other setup needed — the "Read full paper ↗" link on that card will
point straight at it.
